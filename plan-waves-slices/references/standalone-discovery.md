# Standalone Discovery

Use this focused pass only when governance did not supply a valid Discovery Packet.

1. Detect greenfield, brownfield or mixed mode.
2. Identify the plan source and target outcome.
3. Read stack, tests, CI, module boundaries, contracts and integrations.
4. Map current state against the requested target.
5. Record five to ten concise findings with evidence paths.
6. Tag inferences as hypotheses and surface missing intent to the owner.

Do not create a full governance system. Exploration is complete when enough evidence
exists to justify wave boundaries and identify planning blockers.
