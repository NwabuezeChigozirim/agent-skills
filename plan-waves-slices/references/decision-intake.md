# Planning Decision Intake

Ask only when the answer changes scope, ordering, contracts, acceptance, release risk,
or the feasibility of the next wave.

## Individual questions

Use individual owner questions for:

- demonstrable target and explicit cut-line;
- contract consumers and compatibility obligations;
- data migration or destructive behavior;
- authentication, authorization and deployment boundaries;
- acceptance evidence and sign-off responsibility;
- expensive or irreversible dependencies.

## Bundled defaults

Group local, reversible and low-cost defaults into one confirm-or-edit review. Record a
confirmed bundle as explicit decisions only where downstream artifacts need stable IDs.

An accepted decision is binding. A recommendation that still requires implementation
confirmation is not accepted; retain it as an open item.

Facts and observations do not receive D-IDs unless the owner ratifies them as intended
future constraints.
